### Устойчивые позиции чтения

Текущий прогресс основан на проценте прокрутки. Для более точного восстановления позиции дополнительно хранить:

- для PDF — номер страницы;
- для FB2 — ID блока или главы;
- смещение внутри блока.

Это должно сохранять позицию при изменении размера окна, ширины текста, шрифта и других параметров layout.

### Возврат к предыдущему месту чтения

Продумать возможность вернуться к месту, с которого пользователь перешёл в другое место книги через:

- закладку;
- оглавление;
- указание номера страницы
- поисковый переход

Предварительная идея реализации:

- при открытии книги создаётся первый временный якорь;
- его позиция обновляется по мере чтения;
- при переходе через закладку, оглавление или номер страницы создаётся новый временный якорь;
- после перехода прогресс сохраняется уже в новом якоре;
- переходы могут образовывать цепочку, позволяющую вернуться назад, а затем снова перейти вперёд.

Возможное техническое решение — признак текущего якоря в query string URL чтобы работали кнопки назад/вперед в браузере:

- для первого якоря query-параметр отсутствует;
- для последующих якорей используется отдельный query-параметр.

Якоря должны существовать только во время текущего чтения книги и не сохраняться в localStorage или на сервере. После закрытия книги временные якоря удаляются.

Реализовывать этот функционал только после появления оглавления, закладок и перехода по страницам.
