# Book Hub — для агентов

Приватное веб-приложение для хранения и чтения книг.

## Стек

- **Backend:** Go (`backend/`), PostgreSQL, файловое хранилище
- **Frontend:** SolidJS + Vite + TypeScript (`frontend/`)
- **API:** OpenAPI в `api/openapi.yaml`

## Правила при написании фронтенда

* Не запускай сборки или любые другие npm команды, если тебя прямо об этом не просят.
* Во время разработки не выполняй проверки через браузер или playwright, если тебя прямо об этом не просят.
