# PDF Text Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить в существующий SolidJS PDF reader слой pdf.js, позволяющий выделять и копировать встроенный текст PDF.

**Architecture:** Сохранить текущий canvas-рендеринг и IntersectionObserver. Для каждой страницы добавить overlay-контейнер официального pdf.js `TextLayer`, строить его только для видимых страниц и пересобирать при изменении отображаемого размера.

**Tech Stack:** SolidJS, TypeScript, pdfjs-dist 6.1.200, Playwright, SCSS Modules, Storybook.

## Global Constraints

- OCR не добавлять; страницы без встроенного текста остаются только canvas-рендером.
- Backend API не менять.
- Существующие lazy-загрузка, восстановление позиции, ruler и прогресс должны сохраниться.
- Ошибка text layer не должна переводить весь reader в failed state.
- Комментарии не переводить на русский.
- Обновить `docs/APP.md`, потому что меняется пользовательская логика чтения PDF.

### Task 2: Implement the pdf.js text layer

**Files:**
- Modify: `frontend/src/components/common/PdfReader/PdfReader.tsx`
- Modify: `frontend/src/components/common/PdfReader/PdfReader.module.scss`

**Interfaces:**
- Consumes: existing `PDFPageProxy`, `PdfPageDescriptor`, `visiblePages`, `pageWidth`, and `renderPixelRatio`.
- Produces: a `.textLayer` element per page and selectable spans generated by pdf.js.

- [ ] **Step 1: Add text-layer refs and caches**

Add maps next to the existing canvas maps:

```ts
const textLayerRefs = new Map<number, HTMLDivElement>();
const textLayerTasks = new Map<number, pdfjs.TextLayer>();
const textLayerKeys = new Map<number, string>();
```

Use the public `TextLayer` export exposed by the installed `pdfjs-dist` version. If the package only exposes the class from `pdfjs-dist/web/pdf_viewer.mjs`, import its type and runtime value from that exact module, without adding a dependency.

- [ ] **Step 2: Add cancellation and cleanup helpers**

Implement `cancelTextLayerTask(pageNumber)` and `cancelTextLayerTasks()` beside the render-task helpers. Each helper must call the task's `cancel()` method when present, delete the map entry, and leave canvas render state untouched. Add `textLayerRefs.clear()`, `textLayerTasks.clear()`, and `textLayerKeys.clear()` to document reload and component cleanup.

- [ ] **Step 3: Write the minimal text-layer renderer**

Add `renderTextLayer(descriptor)` beside `renderPage`. It must:

1. Read the page and layer from the existing maps and return if either is absent.
2. Compute `displayWidth`, `displayHeight`, ratio, scale, and `viewport` exactly as `renderPage` does.
3. Return when the key `${displayWidth}:${ratio}` is already in `textLayerKeys`.
4. Cancel the previous task, clear `layer.textContent`, and create `new TextLayer({ textContentSource: page.streamTextContent(), container: layer, viewport })`.
5. Await `task.render()`, then record the key only if the component is alive and the current PDF generation is still active.
6. Catch text-layer-specific errors without calling `setFailed(true)`; ignore cancellation errors.
7. Delete the task from the map in `finally` if it is still the active task.

Use `page.getTextContent()` instead of `streamTextContent()` only if the installed pdf.js type/runtime does not support the latter; in that case pass the resolved `TextContent` to `TextLayer` and preserve the same cancellation and generation checks.

- [ ] **Step 4: Invoke text rendering with existing visibility logic**

In the existing render effect, for every visible descriptor call both `void renderPage(descriptor)` and `void renderTextLayer(descriptor)`. Clear `textLayerKeys` whenever `renderedKeys` is cleared because of width or viewport changes.

- [ ] **Step 5: Add the overlay element to each page**

Inside the page `<section>`, keep `<canvas />` and add:

```tsx
<div
  ref={(element) => {
    textLayerRefs.set(page.pageNumber, element);
  }}
  class={styles.textLayer}
  data-testid="pdf-text-layer"
  aria-hidden="true"
/>
```

The layer must be a sibling of canvas, not a wrapper that changes the page's measured aspect ratio.

- [ ] **Step 6: Add overlay styles**

In `PdfReader.module.scss`, make `.page` `position: relative`, keep canvas as a block, and add:

```scss
.textLayer {
  position: absolute;
  inset: 0;
  overflow: hidden;
  line-height: 1;
  user-select: text;
  pointer-events: auto;
  transform-origin: 0 0;

  :global(span) {
    color: transparent;
    cursor: text;
  }

  :global(::selection) {
    background: color-mix(in srgb, var(--accent) 35%, transparent);
  }
}
```

Add any pdf.js-required `.textLayer span` positioning rules from the installed package's viewer CSS if they are not already supplied by `TextLayer`; do not copy unrelated viewer toolbar styles.
