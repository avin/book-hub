# Текстовый слой в PDF-просмотрщике

## Цель

Сделать встроенный текст PDF доступным для выделения мышью и копирования через `Ctrl/Cmd+C`, сохранив текущий canvas-рендеринг, lazy-загрузку страниц, изменение ширины, восстановление позиции и расчет прогресса.

OCR для сканированных страниц не добавляется. Если PDF не содержит встроенного текста, страница остается только графическим canvas-рендером.

## Архитектура

`frontend/src/components/common/PdfReader/PdfReader.tsx` сохраняет canvas как фоновый слой и добавляет поверх каждой страницы официальный текстовый слой pdf.js.

Для каждой страницы используются:

- DOM-ссылка на контейнер текстового слоя;
- задача построения слоя;
- ключ отрисовки, зависящий от отображаемой ширины и device pixel ratio.

Текст строится через `page.getTextContent()` и официальный `TextLayer` pdf.js 6.x с viewport того же масштаба, что и canvas. Текстовый слой строится только для страниц, попавших в текущую область наблюдения IntersectionObserver.

## Жизненный цикл

1. PDF загружается существующим кодом.
2. Для видимой страницы canvas и text layer получают одинаковый display viewport.
3. После получения текстового содержимого pdf.js создает span-элементы в слое.
4. При изменении ширины страницы отменяются устаревшие задачи, очищаются ключи и текстовые слои пересобираются для видимых страниц.
5. При смене документа или размонтировании компонента очищаются ссылки, кэши и активные задачи.

Асинхронные операции проверяют поколение загруженного документа и факт размонтирования компонента, чтобы результат старого PDF не попал в новый DOM.

## Стили и UX

Текстовый слой занимает всю страницу, располагается поверх canvas и принимает pointer events. Canvas остается фоном. Span-элементы текстового слоя получают прозрачный цвет, чтобы текст не отображался поверх растрового текста дважды, но остаются доступными для выделения.

Стили выделения должны быть читаемыми в светлой и темной темах. Существующая панель управления, ruler и поведение прокрутки не меняются.

Ошибка получения текста или построения text layer не блокирует отображение canvas и не переводит весь reader в состояние ошибки.

## Тестирование

- Расширить PDF Storybook-пример документом с текстом.
- Добавить Playwright-тест, который открывает PDF, выделяет текст и проверяет содержимое `window.getSelection().toString()`; системное чтение clipboard проверять только если оно доступно в browser context.
- Прогнать `npm run typecheck`, `npm run lint` и существующий набор e2e-тестов.

## Документация

В `docs/APP.md` добавить краткое описание: встроенный текст PDF можно выделять и копировать, сканированные страницы без текстового слоя остаются недоступны для текстового выделения.

## Границы задачи

В задачу не входят OCR, поиск по тексту, аннотации, подсветка найденных фрагментов, редактирование PDF и изменение backend API.
