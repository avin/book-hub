# Общая читалка книг с фиксированной вёрсткой

PDF и DJVU используют общую читалку книг с фиксированной вёрсткой: единые интерфейс, настройки ширины, расширения страницы, фильтры, поиск, оглавление и прогресс. Библиотека конкретного формата отвечает только за извлечение структуры, текста и растровых страниц; это не допускает расхождения возможностей PDF и DJVU.
