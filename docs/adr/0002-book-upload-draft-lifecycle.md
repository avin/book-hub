# Lifecycle черновика загрузки книги

Черновик загрузки существует до успешного сохранения книги в библиотеке. Batch-загрузка обрабатывает черновики независимо: успешные черновики удаляются из списка, неудачные остаются с сообщением об ошибке, а повтор выполняется обычным повторным нажатием общей кнопки загрузки без отдельного retry-механизма. Ошибка подготовки или отправки обложки не делает загрузку книги неуспешной, потому что обложка необязательна.

Черновики отправляются последовательно. Ошибка одного черновика не прерывает обработку остальных.

Состав batch фиксируется в момент нажатия общей кнопки загрузки; изменения списка во время обработки невозможны благодаря глобальной блокировке страницы.

После полностью успешного batch пользователь переходит в библиотеку. При частичной ошибке пользователь остаётся на странице загрузки и видит причины только у неудачных черновиков; общего сообщения batch не показывается.

Удаление черновика или размонтирование страницы инвалидирует незавершённые операции подготовки: поздние результаты игнорируются, preview URL освобождаются, а ресурсы PDF.js закрываются штатно.

Извлечение названия является отдельным необязательным действием пользователя и не участвует в критериях готовности загрузки. Автоматическая подготовка обложки не блокирует отправку; если она ещё выполняется, книга может быть загружена без обложки, а поздний результат не применяется к завершённому черновику. Ручной выбор обложки недоступен во время автоматической подготовки.

## Consequences

- Пользователь не теряет успешно подготовленные или загруженные книги из-за ошибки соседнего черновика.
- Состояние интерфейса остаётся простым: повтор использует тот же batch-submit.
- Обложку можно добавить только до отправки черновика; поздний результат подготовки не восстанавливает завершённый черновик.
