# Безопасные стили EPUB

Уточняет ADR-0003: адаптивный EPUB применяет только выравнивание текста, начертание, подчёркивание, зачёркивание и разрешённые пробельные режимы из локального CSS книги. Шрифты, размеры, цвета, фон, поля, отступы, позиционирование, at-rules и внешние ресурсы игнорируются, чтобы общие настройки читалки и непрерывная прокрутка оставались предсказуемыми.
