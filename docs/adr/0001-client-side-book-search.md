# Клиентский поиск по тексту открытой книги без OCR

Поиск по книге реализуется внутри reader-а для FB2 и PDF и использует текст, доступный самому reader-у; стандартный поиск браузера, серверный индекс и OCR не используются. Для PDF без встроенного текстового слоя совпадений нет, а границы абзацев, секций и PDF-страниц не пересекаются. Решение сохраняет поиск локальным для открытой книги и не требует отдельной серверной инфраструктуры, одновременно явно ограничивая поддержку сканированных PDF.
