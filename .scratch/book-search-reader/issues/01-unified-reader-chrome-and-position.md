# 01 — Единые панели reader-а и управление позицией

**What to build:** единое фиксированное перекрытие верхней и нижней панелей для FB2 и PDF. Панели появляются и скрываются одновременно, а нижняя панель содержит компактное управление позицией чтения: процент для FB2 и переход по физическому номеру страницы для PDF.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Верхняя и нижняя панели FB2 и PDF отображаются одновременно при наведении на верхнюю или нижнюю область и скрываются после ухода указателя.
- [ ] Панели не изменяют layout и не сдвигают позицию чтения, потому что перекрывают содержимое фиксированно.
- [ ] `Ctrl+F` и `Cmd+F` открывают обе панели и передают фокус поисковому input; весь сохранённый текст input выделяется.
- [ ] `Escape`, кнопка закрытия и клик/тап в `documentShell` закрывают обе панели.
- [ ] При фокусе поискового input панели не скрываются из-за ухода указателя; клик/тап в `documentShell` всё равно закрывает их.
- [ ] На touch-устройствах одинарный тап по центру переключает состояние панелей.
- [ ] Открытие поиска закрывает открытую боковую панель читалки или оглавление.
- [ ] Нижняя панель остаётся однострочной и компактной на узких viewport.
- [ ] В FB2 отображается процент прочитанного без ползунка.
- [ ] В PDF отображается `[текущая физическая страница] / [всего страниц]`.
- [ ] Текущая PDF-страница определяется страницей, пересекающей вертикальный центр viewport.
- [ ] Переход к PDF-странице выполняется по `Enter` или blur, ограничивается диапазоном `1..totalPages` и позиционирует начало страницы с отступом под верхнюю панель.
- [ ] Пока PDF page input в фокусе, автоматическая прокрутка не перезаписывает его значение.
- [ ] Переход по странице и обычная прокрутка обновляют существующий прогресс чтения.
- [ ] Существующие сценарии оглавления, настроек, изменения ширины/настроек reader-а и восстановления позиции остаются рабочими.
- [ ] Краткая документация поведения приложения актуализирована после реализации.
- [ ] Поведение панелей и управления позицией покрыто e2e-тестами на общем reader seam.
