# 01 — Единые панели reader-а и управление позицией

**What to build:** единое фиксированное перекрытие верхней и нижней панелей для FB2 и PDF. Панели появляются и скрываются одновременно, а нижняя панель содержит компактное управление позицией чтения: процент для FB2 и переход по физическому номеру страницы для PDF.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [x] Верхняя и нижняя панели FB2 и PDF отображаются одновременно при наведении на верхнюю или нижнюю область и скрываются после ухода указателя.
- [x] Панели не изменяют layout и не сдвигают позицию чтения, потому что перекрывают содержимое фиксированно.
- [x] `Ctrl+F` и `Cmd+F` открывают обе панели и передают фокус поисковому input; весь сохранённый текст input выделяется.
- [x] `Escape` и клик/тап в `documentShell` закрывают обе панели.
- [x] При фокусе поискового input панели не скрываются из-за ухода указателя; клик/тап в `documentShell` всё равно закрывает их.
- [x] На touch-устройствах одинарный тап по центру переключает состояние панелей.
- [x] Открытие поиска закрывает открытую боковую панель читалки или оглавление.
- [x] Нижняя панель остаётся однострочной и компактной на узких viewport.
- [x] В FB2 отображается процент прочитанного без ползунка.
- [x] В PDF отображается `[текущая физическая страница] / [всего страниц]`.
- [x] Текущая PDF-страница определяется страницей, пересекающей вертикальный центр viewport.
- [x] Переход к PDF-странице выполняется по `Enter` или blur, ограничивается диапазоном `1..totalPages` и позиционирует начало страницы с отступом под верхнюю панель.
- [x] Пока PDF page input в фокусе, автоматическая прокрутка не перезаписывает его значение.
- [x] Переход по странице и обычная прокрутка обновляют существующий прогресс чтения.
- [x] Существующие сценарии оглавления, настроек, изменения ширины/настроек reader-а и восстановления позиции остаются рабочими.
- [x] Краткая документация поведения приложения актуализирована после реализации.
- [x] Поведение панелей и управления позицией покрыто e2e-тестами на общем reader seam.

## Comments

Реализовано в текущей ветке: общий фиксированный верхний/нижний overlay для FB2 и PDF, keyboard/touch управление, FB2-процент и PDF-переход по физической странице. Добавлены e2e-проверки и актуализирована `docs/APP.md`.
