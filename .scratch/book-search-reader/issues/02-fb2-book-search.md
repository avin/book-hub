# 02 — Поиск по FB2

**What to build:** полностью рабочий поиск по тексту открытой FB2-книги через общий нижний control панелей. Поиск запускается только явным действием, подсвечивает совпадения, навигирует по ним циклически и учитывает сноски в их расположении в конце книги.

**Blocked by:** 01 — Единые панели reader-а и управление позицией.

**Status:** ready-for-agent

- [ ] В нижней панели есть компактный input с placeholder `Поиск по книге`, без визуального label, но с доступным именем.
- [ ] Изменение текста input само по себе не запускает поиск и не меняет текущие подсветку, счётчик или активное совпадение.
- [ ] `Enter`, «Найти следующее» и «Найти предыдущее» используют актуальный текст input и запускают поиск.
- [ ] При получении фокуса весь сохранённый текст input выделяется.
- [ ] Запрос очищается от начальных и конечных пробелов; пустой или состоящий только из пробелов запрос не создаёт совпадений.
- [ ] Поиск регистронезависимый, выполняется по обычной подстроке и нормализует пробелы/переносы внутри одной поисковой области.
- [ ] Совпадение не пересекает границы абзаца или секции.
- [ ] Текст сносок находится в их расположении в конце FB2 и участвует в поиске.
- [ ] Все найденные совпадения подсвечиваются, активное совпадение выделяется контрастнее.
- [ ] Активное совпадение прокручивается примерно в центр viewport.
- [ ] Первый поиск начинается относительно текущей позиции чтения; «следующее» ищет вперёд, «предыдущее» — назад.
- [ ] Последующий переход идёт относительно активного совпадения и циклически переходит через начало/конец книги.
- [ ] Ручная прокрутка не сбрасывает активное совпадение и точку навигации.
- [ ] До выполненного поиска и при отсутствии результатов отображается компактный серый `0/0`; при результатах отображается `N/M` обычным цветом.
- [ ] `Escape`, кнопка закрытия и клик/тап в `documentShell` снимают подсветку, но сохраняют текст запроса.
- [ ] После повторного открытия новый явный поиск по сохранённому запросу снова создаёт подсветку.
- [ ] Переход к совпадению обновляет и сохраняет прогресс чтения.
- [ ] Поиск и навигация покрыты e2e-тестами на общем seam и FB2-адаптере.
