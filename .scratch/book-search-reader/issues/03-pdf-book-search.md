# 03 — Поиск по PDF

**What to build:** подключить PDF reader к общему поисковому control и реализовать поиск по текстовым слоям PDF с постраничными совпадениями, подсветкой, циклической навигацией и синхронизацией с номером текущей страницы.

**Blocked by:** 02 — Поиск по FB2.

**Status:** ready-for-agent

- [ ] PDF использует тот же компактный search input, кнопки, счётчик и поведение открытия/закрытия, что и FB2.
- [ ] Поиск выполняется по тексту каждой PDF-страницы с встроенным текстовым слоем.
- [ ] Совпадение не пересекает границу PDF-страницы.
- [ ] Для PDF без встроенного текстового слоя OCR не запускается, счётчик показывает `0/0`.
- [ ] Все совпадения подсвечиваются, активное совпадение выделяется контрастнее.
- [ ] Активное совпадение прокручивается примерно в центр viewport и обновляет текущий номер страницы.
- [ ] Первый поиск начинается относительно текущей позиции чтения, последующая навигация идёт относительно активного совпадения.
- [ ] Навигация «следующее»/«предыдущее» циклически переходит через границы всего документа.
- [ ] Изменение текста input без `Enter` или кнопки не меняет текущие результаты.
- [ ] `Escape`, закрытие панели и клик/тап в `documentShell` снимают PDF-подсветку, сохраняя текст запроса.
- [ ] Переход к совпадению обновляет и сохраняет прогресс чтения.
- [ ] Существующие PDF canvas, текстовый слой, lazy rendering, оглавление и изменение ширины страницы остаются рабочими.
- [ ] Поиск по PDF и его взаимодействие с номером страницы покрыты e2e-тестами, включая документ без текстового слоя.
