# 01: Разделить хранение файлов книг и изображений приложения

**What to build:** подготовить отдельную работу с исходными файлами книг и локальными изображениями, сохранив все существующие операции локальной установки. Это подготовительный рефакторинг перед добавлением новых мест хранения; пользователь продолжает загружать, читать, скачивать и удалять книги как прежде.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**Основание:** [спецификация](../spec.md), истории 10, 12–15, 46; ADR-0008, ADR-0002.

- [ ] Исходный файл книги означает целый PDF, DJVU, FB2 или EPUB со встроенными иллюстрациями; отдельные обложки и JPEG-миниатюры остаются локальными изображениями приложения.
- [ ] Работа с оригиналами отделена от операций с изображениями и временными файлами. Подключение выбранного хранилища можно использовать в HTTP-сервере, admin CLI и backup/restore без дублирования правил хранения.
- [ ] Прежняя локальная конфигурация и сохранённые абсолютные или относительные пути продолжают работать без ручного переноса. Задача не меняет содержимое оригиналов или формат существующих копий.
- [ ] Загрузка, чтение, скачивание, редактирование обложки, удаление книги и удаление пользователя сохраняют прежнее внешнее поведение. Необязательность обложки, глобальная дедупликация, уникальность пары пользователь/файл и учёт квоты не меняются.
- [ ] Проверка доступа выполняется до выдачи исходного файла; сохраняются MIME-типы, Unicode-имена, inline/attachment и существующая поддержка частичных запросов.
- [ ] Существующий локальный backup/restore и подготовка локальных директорий продолжают работать. Новые протоколы, очередь удаления и кэш в этой задаче не включаются.
- [ ] Проходят релевантные существующие HTTP-, файловые и backup-проверки и сборка использующих хранение приложений. Добавляются только проверки значимых внешних гарантий, которые не покрыты существующими тестами.

**Проверка результата:** на прежней конфигурации загрузить книгу с обложкой, прочитать и скачать её, выполнить локальный backup/restore и удалить книгу; отдельно проверить общий оригинал двух пользователей и удаление пользователя через CLI.
