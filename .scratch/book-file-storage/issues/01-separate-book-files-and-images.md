# 01: Разделить хранение файлов книг и изображений приложения

**What to build:** подготовить отдельную работу с исходными файлами книг и локальными изображениями, сохранив все существующие операции локальной установки. Это подготовительный рефакторинг перед добавлением новых мест хранения; пользователь продолжает загружать, читать, скачивать и удалять книги как прежде.

**Blocked by:** None (can start immediately).

**Status:** resolved

**Основание:** [спецификация](../spec.md), истории 10, 12–15, 46; ADR-0008, ADR-0002.

- [x] Исходный файл книги означает целый PDF, DJVU, FB2 или EPUB со встроенными иллюстрациями; отдельные обложки и JPEG-миниатюры остаются локальными изображениями приложения.
- [x] Работа с оригиналами отделена от операций с изображениями и временными файлами. Подключение выбранного хранилища можно использовать в HTTP-сервере, admin CLI и backup/restore без дублирования правил хранения.
- [x] Прежняя локальная конфигурация и сохранённые абсолютные или относительные пути продолжают работать без ручного переноса. Задача не меняет содержимое оригиналов или формат существующих копий.
- [x] Загрузка, чтение, скачивание, редактирование обложки, удаление книги и удаление пользователя сохраняют прежнее внешнее поведение. Необязательность обложки, глобальная дедупликация, уникальность пары пользователь/файл и учёт квоты не меняются.
- [x] Проверка доступа выполняется до выдачи исходного файла; сохраняются MIME-типы, Unicode-имена, inline/attachment и существующая поддержка частичных запросов.
- [x] Существующий локальный backup/restore и подготовка локальных директорий продолжают работать. Новые протоколы, очередь удаления и кэш в этой задаче не включаются.
- [x] Проходят релевантные существующие HTTP-, файловые и backup-проверки и сборка использующих хранение приложений. Добавляются только проверки значимых внешних гарантий, которые не покрыты существующими тестами.

**Проверка результата:** на прежней конфигурации загрузить книгу с обложкой, прочитать и скачать её, выполнить локальный backup/restore и удалить книгу; отдельно проверить общий оригинал двух пользователей и удаление пользователя через CLI.


## Answer

Реализовано в `7e3f7cc`: `files.Store` собирает отдельные `Books` (локальные оригиналы), `Images` (обложки и миниатюры), `Work` (временные файлы). Операции оригиналов используют context. HTTP и admin CLI обращаются к оригиналам через `Books`; содержимое книг, прежние пути и структура локальных архивов сохранены.

Проверки: `go test ./...` с отдельной PostgreSQL-базой, дополнительные проверки целого оригинала с бинарными иллюстрациями, абсолютных/относительных старых путей и удаления пользователя с общим оригиналом; `go build ./cmd/...`. Повторно прошли HTTP-, файловые и admin-тесты после финальной правки очистки при отменённом запросе. Существующий SQLite backup/restore прошёл; PostgreSQL backup с внешними pg tools здесь не запускался. Frontend и E2E не запускались: пользовательское поведение и контракт не изменены.
