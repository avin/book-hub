# 12: Проверка полного сценария развёртывания

**What to build:** подтвердить готовность всей доработки в поддерживаемых способах запуска: сервер, CLI, миграции, реальные хранилища, кэш и перенос через backup/restore работают вместе, а эксплуатационные инструкции соответствуют итоговому поведению.

**Blocked by:** 10 — Backup/restore через удалённые хранилища; 11 — Совместная работа нескольких backend.

**Status:** ready-for-agent

**Основание:** [спецификация](../spec.md), все пользовательские истории и группы обязательных проверок; ADR-0008, ADR-0009, ADR-0010.

- [ ] Поддерживаемые конфигурации запуска передают согласованные параметры серверу, admin CLI, backup CLI и мигратору. Проверены обе СУБД и оба варианта Compose; существующая локальная установка обновляется без ручного переноса.
- [ ] Серверное и административные приложения собираются, миграции SQLite/PostgreSQL проходят, существующие гарантии сборки сохраняются.
- [ ] Протокольные интеграционные проверки запускают реальные локальные FTP, explicit/implicit FTPS и S3-совместимый сервис и не требуют внешнего аккаунта пользователя. Выполнен общий цикл загрузки, чтения, скачивания и удаления с включённым кэшем для каждого типа хранения.
- [ ] Подтверждён сценарий HDD/SSD: повторная выдача, запуск с сохранённым кэшем и периодическая проверка готовности не обращаются к оригиналам. Сохранены работа при отказах, строгие бюджеты и освобождение ресурсов.
- [ ] Проверены сохраняемая очередь и конкурентные операции на обеих СУБД, а также два backend на PostgreSQL с независимыми кэшами. Применимые проверки выполнены с детектором гонок.
- [ ] Полный цикл backup/restore выполнен в поддерживаемой среде с разными типами исходного и целевого хранилища. Подтверждены прежний комплект копии, старые поддерживаемые архивы и отсутствие зависимости восстановленной библиотеки от исходного сервиса.
- [ ] HTTP-контракт и клиентские типы согласованы с итоговыми ошибками и выдачей. Существующие frontend-проверки подтверждают работу читалок и скачивания; при изменении обработки ошибки проверено соответствующее пользовательское поведение.
- [ ] Описание текущего поведения и инструкции разработки/развёртывания актуализированы: один тип хранения на библиотеку, локальные изображения, оба FTPS, проверенные S3-сервисы, кэш по умолчанию выключен, отдельный рабочий лимит 1 ГиБ, восстановление в пустое место и ручной повтор после сбоя.
- [ ] Итоговая проверка охватывает все обязательные группы спецификации. Для пропущенных проверок указаны конкретные причины; пропуск внешнего сервиса или PostgreSQL не считается прохождением соответствующего контракта.
- [ ] Исправлены обнаруженные при совместной проверке несогласованности в пределах этой доработки. SFTP, импорт коллекций, отдельный перенос и другие исключённые возможности не добавлены.

**Проверка результата:** выполнить документированный сценарий новой установки, добавления и повторного открытия книги, временного отказа источника, удаления и полного переноса библиотеки через backup/restore; сверить результат с обязательными группами спецификации.
