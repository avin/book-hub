# 08: Объединение одновременных получений

**What to build:** одновременные запросы одной книги используют одно получение на экземпляр backend. Отмена клиента, ошибки и повторные запросы не обрывают соседние выдачи и не оставляют занятыми файлы или лимиты.

**Blocked by:** 07 — Постоянный локальный кэш с LRU.

**Status:** ready-for-agent

**Основание:** [спецификация](../spec.md), истории 26, 28, 30, 31, 34–37; ADR-0009.

- [ ] Одновременные чтение и скачивание одного исходного файла вызывают одно получение на экземпляр backend, в том числе при запросах разных пользователей с подтверждённым доступом.
- [ ] Объединение применяется к получению в кэш и к общему временному файлу при обходе кэша. Готовый временный файл остаётся доступным до завершения использующих его выдач.
- [ ] Каждый запрос проходит свою проверку доступа до присоединения к получению; знание идентичности файла или наличие ожидающего владельца не открывает его чужому пользователю.
- [ ] Уход одного ожидающего клиента не отменяет получение для остальных. При отсутствии ожидающих незавершённая операция отменяется, а временные файлы и резервы освобождаются.
- [ ] После успешного общего получения каждый оставшийся запрос получает корректный ответ, включая свой диапазон или режим скачивания. Активная выдача не теряет файл из-за завершения другой выдачи.
- [ ] Ошибка источника, целостности или локальной записи завершает ожидающие запросы корректной ошибкой. Следующий запрос может начать новое получение; зависшей общей операции не остаётся.
- [ ] При одновременных отменах, ошибках и новых запросах соблюдаются отдельные бюджеты кэша и рабочей директории; учёт места не освобождается раньше фактического прекращения его использования.
- [ ] Конкурентные HTTP-тесты используют управляемые события источника и наблюдаемое число получений вместо случайных задержек. Проверки с детектором гонок выполняются там, где применимы.

**Проверка результата:** одновременно запросить один отсутствующий файл несколькими клиентами, отменить часть запросов и завершить оставшиеся; затем отменить всех и повторить запрос, проверив число получений и освобождение места.
