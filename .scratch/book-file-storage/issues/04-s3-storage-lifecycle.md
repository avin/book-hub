# 04: Полный цикл хранения в S3

**What to build:** администратор выбирает S3, а пользователь загружает, читает, скачивает и удаляет книги через обычный интерфейс. Оригиналы находятся в выбранном бакете и префиксе, изображения остаются локальными.

**Blocked by:** 03 — Отдельная директория оригиналов и ограниченные рабочие файлы.

**Status:** claimed

**Основание:** [спецификация](../spec.md), истории 7, 8, 12–16, 42, 43, 46; ADR-0008.

- [ ] Поддерживаются Amazon S3 и проверенный S3-совместимый сервис. Endpoint, регион, бакет, префикс и учётные данные задаются серверной конфигурацией без пользовательской страницы настроек.
- [ ] HTTP-загрузка сохраняет целый исходный файл в выбранной области S3; обложки и миниатюры сохраняются локально. Успех не подтверждается при неуспешном сохранении оригинала.
- [ ] Чтение и скачивание проходят через общий механизм backend с проверкой доступа, полного размера и SHA-256; сохраняются частичная выдача и прежние заголовки. Прямые ссылки S3 браузеру не выдаются.
- [ ] Повторная загрузка одинакового содержимого, квоты, общий оригинал и удаление последней ссылки используют общие правила приложения. Адаптер не вводит собственный альтернативный жизненный цикл или очередь.
- [ ] Операции приложения ограничены выделенной областью; получение и удаление файлов из другого префикса не требуются для работы библиотеки.
- [ ] Недоступность сервиса, ошибка аутентификации, обрыв получения и повреждение содержимого обрабатываются через принятый механизм ошибок и освобождения рабочих файлов.
- [ ] Настоящий адаптер проверен на локальном S3-совместимом сервере: запись, чтение, удаление, префикс, настроенный endpoint и отказ источника. Проверка не требует облачного аккаунта пользователя.
- [ ] Настройки передаются в поддерживаемых вариантах запуска сервера и CLI; документация описывает подключение и фактически проверенный сервис без обещания совместимости со всеми реализациями S3.

**Проверка результата:** добавить книгу с обложкой, прочитать и скачать её через HTTP, убедиться в размещении оригинала в нужном префиксе и изображения локально, проверить дедупликацию и удаление; затем повторить получение при сбое источника.
