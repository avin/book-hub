# 04: Полный цикл хранения в S3

**What to build:** администратор выбирает S3, а пользователь загружает, читает, скачивает и удаляет книги через обычный интерфейс. Оригиналы находятся в выбранном бакете и префиксе, изображения остаются локальными.

**Blocked by:** 03 — Отдельная директория оригиналов и ограниченные рабочие файлы.

**Status:** resolved

**Основание:** [спецификация](../spec.md), истории 7, 8, 12–16, 42, 43, 46; ADR-0008.

- [x] Поддерживаются Amazon S3 и проверенный S3-совместимый сервис. Endpoint, регион, бакет, префикс и учётные данные задаются серверной конфигурацией без пользовательской страницы настроек.
- [x] HTTP-загрузка сохраняет целый исходный файл в выбранной области S3; обложки и миниатюры сохраняются локально. Успех не подтверждается при неуспешном сохранении оригинала.
- [x] Чтение и скачивание проходят через общий механизм backend с проверкой доступа, полного размера и SHA-256; сохраняются частичная выдача и прежние заголовки. Прямые ссылки S3 браузеру не выдаются.
- [x] Повторная загрузка одинакового содержимого, квоты, общий оригинал и удаление последней ссылки используют общие правила приложения. Адаптер не вводит собственный альтернативный жизненный цикл или очередь.
- [x] Операции приложения ограничены выделенной областью; получение и удаление файлов из другого префикса не требуются для работы библиотеки.
- [x] Недоступность сервиса, ошибка аутентификации, обрыв получения и повреждение содержимого обрабатываются через принятый механизм ошибок и освобождения рабочих файлов.
- [x] Настоящий адаптер проверен на локальном S3-совместимом сервере: запись, чтение, удаление, префикс, настроенный endpoint и отказ источника. Проверка не требует облачного аккаунта пользователя.
- [x] Настройки передаются в поддерживаемых вариантах запуска сервера и CLI; документация описывает подключение и фактически проверенный сервис без обещания совместимости со всеми реализациями S3.

**Проверка результата:** добавить книгу с обложкой, прочитать и скачать её через HTTP, убедиться в размещении оригинала в нужном префиксе и изображения локально, проверить дедупликацию и удаление; затем повторить получение при сбое источника.

## Answer

Реализация: `43e7a87`, согласование общего server/CLI loader — `ab48a8c`. Официальный AWS SDK v2 используется через общий `files.Originals`; endpoint по умолчанию определяется по региону Amazon S3, заданный endpoint использует path-style. Область ограничена обязательным префиксом. Multipart получает seekable временный файл, отмена дополнительно удаляет незавершённые части отдельным ограниченным контекстом. Constructor не выполняет сетевых запросов.

Проверено на Garage v2.5.0: полный HTTP-жизненный цикл с локальными изображениями, дедупликация, отсутствие чужого доступа, повреждённый оригинал с 503 и успешным повтором, ошибка аутентификации без потери сессии, удаление последнего владельца, idempotent delete, границы соседних префиксов и отмена multipart без оставшихся частей. Реальные `TestS3*` выполнены в Linux с `-race -p 2`, `BOOK_HUB_TEST_S3_ENDPOINT=http://storage-s3:3900`. Host config/files/HTTP `-race`, полный `go test ./...` и `go build ./cmd/...` прошли. Облачный аккаунт Amazon не использовался. Frontend не менялся; E2E выполнены корневым агентом для общей интеграции.
