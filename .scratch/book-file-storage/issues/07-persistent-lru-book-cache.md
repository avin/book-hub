# 07: Постоянный локальный кэш с LRU

**What to build:** пользователь повторно читает и скачивает книгу из ограниченного локального кэша без обращения к оригиналу, в том числе на спящем HDD. Кэш сохраняется между перезапусками и безопасно обходится, если использовать его нельзя.

**Blocked by:** 03 — Отдельная директория оригиналов и ограниченные рабочие файлы.

**Status:** claimed

**Основание:** [спецификация](../spec.md), истории 17–29, 32–34, 38–41, 44, 45; ADR-0008, ADR-0009.

- [ ] Кэш по умолчанию выключен. Для включения явно задаются локальный путь и положительный максимальный размер; некорректные значения обнаруживаются при запуске.
- [ ] Один механизм кэширования применяется к директории и подключаемым удалённым источникам, к чтению и скачиванию. Готовая копия одинакового исходного файла общая для пользователей одного backend; право доступа проверяется перед каждой выдачей.
- [ ] При попадании отсутствуют обращения к оригиналу, включая чтение, stat и HEAD. Это проверяется управляемым источником, который фиксирует или запрещает любое обращение.
- [ ] При промахе целый файл получен и проверен до публикации готовой копии и начала выдачи. Уже проверенная копия заново целиком на каждом запросе не хешируется.
- [ ] Лимит учитывает готовые и скачиваемые в кэш файлы; место под полный размер резервируется заранее. Совокупный бюджет соблюдается при параллельных получениях разных книг.
- [ ] Чтение и скачивание обновляют LRU. Текущие выдачи защищены от вытеснения; при невозможности освободить место лимит не превышается.
- [ ] Завершённые копии переживают перезапуск, незавершённые убираются. Проверка и использование сохранённого кэша при запуске не требуют доступности оригиналов.
- [ ] Слишком большой файл, отключённый, заполненный или неисправный кэш используют общий обход: локальный оригинал напрямую, удалённый через отдельно ограниченную рабочую директорию. Ошибка кэша фиксируется в логе и не блокирует доступный обход или запуск backend.
- [ ] После успешной загрузки уже принятый файл по возможности остаётся в кэше без обратного скачивания. Ошибка кэша или обложки не отменяет успешное сохранение оригинала.
- [ ] При недоступных оригиналах кэшированные книги доступны после проверки прав. Промах возвращает временную ошибку без потери сессии; readiness не проверяет оригиналы и не блокируется только из-за необязательного кэша при рабочем обходе.
- [ ] HTTP-проверки покрывают LRU, лимит, активную выдачу, перезапуск, целостность, права разных пользователей и работу с отключённым источником. Настройки и сценарий HDD/SSD описаны в документации.

**Граница:** объединение нескольких незавершённых запросов одной книги и правила отмены общего получения завершаются в задаче 08; строгий бюджет и отсутствие дубликатов готовых копий обязательны уже здесь.

**Проверка результата:** получить книгу в кэш, отключить оригиналы, перезапустить backend и прочитать её снова; затем проверить вытеснение другой книги и обход для файла, который не помещается.
