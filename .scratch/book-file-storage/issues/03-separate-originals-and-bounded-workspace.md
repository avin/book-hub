# 03: Отдельная директория оригиналов и ограниченные рабочие файлы

**What to build:** администратор размещает оригиналы отдельно от локальных изображений и рабочих файлов. Backend получает и проверяет книгу перед выдачей, ограничивает временное место и не обращается к оригиналам при периодической проверке готовности.

**Blocked by:** 01 — Разделить хранение файлов книг и изображений приложения.

**Status:** resolved

**Основание:** [спецификация](../spec.md), истории 1, 9–11, 13–16, 21, 23, 25, 30, 31, 41–43; ADR-0008, ADR-0009.

- [x] Для всей библиотеки настраивается одно хранилище; на этом этапе доступна директория оригиналов отдельно от локальных изображений и рабочей директории. Прежняя локальная конфигурация остаётся рабочей.
- [x] Настройки задаются переменными окружения и применяются после перезапуска. Некорректные значения обнаруживаются при запуске; изображениями и локальными рабочими файлами по-прежнему управляет backend.
- [x] Временные файлы загрузки новых книг и получения оригиналов имеют общий настраиваемый лимит, по умолчанию 1 ГиБ на экземпляр. Учитываются одновременно выполняемые операции, включая используемые ими промежуточные файлы.
- [x] Исчерпание рабочего бюджета отклоняет новую операцию временной ошибкой, сохраняя текущие выдачи. Ошибки и отмена освобождают принадлежащие операции файлы и резервы.
- [x] Общий путь получения поддерживает управляемый источник оригиналов для последующих протокольных адаптеров. Удалённый оригинал целиком сохраняется локально, проверяется по размеру и SHA-256 и только затем выдаётся; локальный оригинал без кэша выдаётся напрямую после необходимой проверки.
- [x] Обрыв, неверный размер или SHA-256 не приводят к выдаче частичного файла. Временный файл удаляется после завершения использующих его выдач.
- [x] Сохраняются авторизация и ownership, inline/attachment, MIME-типы, Unicode-имена, HEAD, Content-Length, диапазоны с 206/416 и применимое условное получение. Временные ошибки используют 503 service_unavailable в существующем формате и не сбрасывают сессию.
- [x] Backend допускает недоступность оригиналов при запуске. Периодическая проверка готовности проверяет необходимые локальные ресурсы и БД отдельно, не выполняя чтение или проверку метаданных оригиналов.
- [x] Успех новой загрузки означает сохранение в основном хранилище и библиотеке, а не только наличие временного файла. Готовность будущего протокольного адаптера проверяется через HTTP с управляемыми задержками, сбоями и повреждениями источника.
- [x] Настройки доступны серверу и применимым CLI; конфигурация запуска и HTTP-контракт актуализированы. При изменении публичного контракта согласованно обновлены клиентские обёртки и сгенерированные типы.

**Проверка результата:** отдельно разместить оригиналы и изображения, ограничить рабочее место и проверить через HTTP успешную выдачу, отказ нового получения при заполненном бюджете, отсутствие частичной выдачи и отсутствие обращений к оригиналам со стороны readiness.

## Answer

Реализация: `fe2e3b2`; совместимость с задачей 02: `7423aef`.
Общие операции находятся в `files.Originals`, `Store.OpenBook` и ограниченном `Workspace`.
Multipart-загрузка идёт сразу в учтённый рабочий файл; `TempFile.Release` освобождает файл и резерв.
Оригиналы сохраняются атомарным копированием с сохранением принятого файла до Release, что допускает разные файловые системы и заполнение будущего кэша без обратного чтения.

Проверки: полный `go test ./...` на Windows с отдельной настоящей PostgreSQL; полный Linux
`go test -p 2 -race ./...` с PostgreSQL 17, pg_dump/psql 17, SQLite, backup/restore и старыми копиями;
`go build ./cmd/...`; генерация OpenAPI-типов. HTTP-проверки воспроизводят повреждения, обрыв,
отмену, общий бюджет, очистку после перезапуска, независимые изображения, HEAD/206/416/304 и проверку доступа до оригинала.
Публичные клиентские функции используют прежний binary endpoint и уже передают ошибку 503 вызывающему коду без сброса сессии; их форма не менялась.
E2E не запускались: пользовательские сценарии frontend не менялись; общая frontend-регрессия выполняется в итоговой задаче 12.
