# 02: Надёжное удаление оригиналов

**What to build:** удаление книги сразу убирает её из библиотеки, а оригинал без владельцев надёжно удаляется через сохраняемую очередь. Временный сбой хранилища и конкурентная повторная загрузка не приводят к потере используемых файлов.

**Blocked by:** 01 — Разделить хранение файлов книг и изображений приложения.

**Status:** ready-for-agent

**Основание:** [спецификация](../spec.md), истории 46–51; ADR-0008.

- [ ] Удаление пользовательской записи сразу убирает книгу и связанные с ней данные из библиотеки; сбой удаления оригинала не отменяет этот результат. Локальные обложки обрабатываются как прежде.
- [ ] Общий оригинал сохраняется, пока существует хотя бы одна пользовательская ссылка. Задача удаления появляется при удалении последней ссылки и сохраняется надёжно вместе с изменением состояния библиотеки.
- [ ] Очередь хранится в БД, переживает перезапуск и повторяет удаление после временных сбоев. Уже отсутствующий оригинал не оставляет бесконечно невыполнимую задачу.
- [ ] Перед повтором проверяется отсутствие новых ссылок; эта проверка и удаление согласованы с конкурентной загрузкой того же содержимого. Одна предварительная проверка без защиты последующего удаления не считается выполнением требования.
- [ ] Две конкурентные загрузки одинакового нового файла не приводят к удалению общего оригинала при конфликте или откате одной из них.
- [ ] Удаление пользователя через admin CLI использует тот же жизненный цикл. При остановленном backend задача сохраняется для последующей обработки.
- [ ] Необходимые миграции и операции поддерживаются на SQLite и PostgreSQL с сохранением штатного порядка миграций.
- [ ] Проверки с реальными SQLite и PostgreSQL воспроизводят сбой удаления, перезапуск, повторную загрузку и конкурентный доступ через независимые подключения. Межпроцессная защита PostgreSQL не подменяется блокировкой внутри одного процесса.

**Проверка результата:** отключить удаление в управляемом источнике, удалить последнюю пользовательскую запись, перезапустить обработчик и восстановить источник; оригинал должен удалиться, а вновь используемый оригинал — сохраниться.
