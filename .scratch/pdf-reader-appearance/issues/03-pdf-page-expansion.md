# 03 — Расширение страницы PDF

**What to build:** В подразделе «Страница» PDF-панели работает ползунок «Расширение страницы» от 0 до 25 % с шагом 1 %. Настройка сохраняется только для текущей книги в localStorage. Она пропорционально увеличивает страницу, текстовый слой и подсветку поиска, выводя за пределы области чтения только левый и правый края страницы. Изменение применяется после отпускания ползунка и не зависит от WebGL.

**Blocked by:** 01 — Панель «Внешний вид» и действия PDF.

**Status:** ready-for-agent

- [ ] Ползунок принимает целые значения 0–25 %, по умолчанию равен 0 % и применяет изменение после завершения перетаскивания.
- [ ] Расширение сохраняется и восстанавливается отдельно для каждой PDF-книги, не меняя исходный файл, общую ширину PDF или настройки другой книги.
- [ ] При расширении страница и её текстовый слой масштабируются пропорционально; боковые края скрываются, а поиск, выделение и подсветка остаются геометрически синхронизированы с текстом.
- [ ] Ползунок остаётся доступным, когда WebGL-фильтры недоступны; обработка фильтров сохраняет прежнее поведение.
- [ ] Playwright e2e-тесты проверяют диапазон, сохранение, сброс, пропорциональную геометрию и сохранность поиска без проверки внутренней реализации canvas/WebGL.
- [ ] Пользовательская документация приложения описывает обновлённую панель «Внешний вид», расширение страницы и локальную область хранения настроек.
