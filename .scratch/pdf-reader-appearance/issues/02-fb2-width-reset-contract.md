# 02 — Семантика сброса и автоширины FB2

**What to build:** В FB2-читалке «Сбросить» изменяет только параметры внешнего вида и сохраняет текущую выбранную ширину текста. «Автоширина» остаётся единственным действием, которое снимает это ограничение, чтобы поведение совпадало с PDF-панелью «Внешний вид».

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Нажатие «Сбросить» после установки пользовательской ширины текста сохраняет её значение и сбрасывает остальные параметры внешнего вида.
- [ ] Нажатие «Автоширина» снимает ограничение ширины текста, не подменяя собой сброс параметров внешнего вида.
- [ ] Поведение закреплено Playwright e2e-тестом через существующую панель «Внешний вид» FB2.
