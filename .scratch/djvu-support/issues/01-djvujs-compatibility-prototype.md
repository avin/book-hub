# 01 — Проверочный прототип DjVu.js

**What to build:** Изолированный прототип DjVu.js 0.5.4 на трёх bundled DJVU: скан без OCR, документ с OCR-слоем и документ с NAVM-оглавлением. Прототип не меняет пользовательский API и не добавляет DJVU в продукт.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Зафиксированы воспроизводимый способ подключения библиотеки и Worker API в Vite-сборку, а также необходимые лицензионные уведомления.
- [ ] Для каждой фикстуры подтверждены: определение bundled-документа, список и размеры страниц, отрисовка первой страницы в canvas и освобождение Worker-ресурсов.
- [ ] Для OCR-фикстуры подтверждены получение текста и нормализованных текстовых зон; для NAVM-фикстуры — вложенная структура и внутренние/внешние цели.
- [ ] Проверены границы производительности и памяти для отрисовки видимых страниц; результаты и известные неподдерживаемые chunk-типы записаны в комментарии к задаче.
- [ ] К следующим задачам приложены разрешённые для репозитория фикстуры либо воспроизводимые инструкции их получения.
