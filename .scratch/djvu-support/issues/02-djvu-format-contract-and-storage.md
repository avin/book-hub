# 02 — Контракт и хранение формата DJVU

**What to build:** Backend, OpenAPI и сгенерированные frontend-типы поддерживают формат `djvu`; хранилище и загрузка определяют его только по расширениям `.djvu` и `.djv`.

**Blocked by:** 01 — Проверочный прототип DjVu.js.

**Status:** ready-for-agent

- [ ] В доменной модели, миграции PostgreSQL, файловом хранилище, API и сгенерированной схеме появляется формат `djvu` без изменения поведения PDF/FB2/EPUB.
- [ ] Загрузочный endpoint принимает только `.djvu` и `.djv` как варианты DJVU; остальные расширения не становятся допустимыми.
- [ ] Ответы библиотеки, получение исходного файла, скачивание, карточки и маршрутизация книги корректно обрабатывают новый формат.
- [ ] Миграционные, HTTP- и frontend-контрактные тесты покрывают добавление формата и не допускают регрессию существующих значений.
