# 06 — Оглавление и поиск DJVU

**What to build:** DJVU использует в общей читалке встроенное NAVM-оглавление и OCR-текстовый слой для поиска, подсветки, выделения и копирования.

**Blocked by:** 05 — Рендеринг DJVU в общей читалке.

**Status:** ready-for-agent

- [ ] NAVM-пункты отображаются с исходной вложенностью; при отсутствии NAVM кнопка оглавления недоступна.
- [ ] Внутренняя цель оглавления прокручивает к соответствующей странице, внешняя URL-цель открывается безопасно в новой вкладке.
- [ ] OCR-текст и нормализованные зоны формируют выровненный поверх страницы текстовый слой, пригодный для выделения, копирования и подсветки.
- [ ] Поиск DJVU совпадает с поведением PDF по вводу, количеству совпадений, переходу вперёд/назад и подсветке.
- [ ] Если DJVU не содержит OCR-текста, поиск обозначается как недоступный, а не как пустая выдача.
- [ ] E2E-тесты покрывают вложенное оглавление, оба типа ссылок, поиск с OCR, недоступный поиск без OCR и работу текста поверх фильтрованной страницы.
