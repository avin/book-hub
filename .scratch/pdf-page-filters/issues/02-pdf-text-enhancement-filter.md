# 02 — Усиление текста для PDF-страниц

**What to build:** Читатель PDF-книги может включить фильтр «Усиление текста» и настроить толщину штриха, порог, контраст, число уровней серого и сдвиг тона. Включённые фильтры применяются к растровому изображению страниц, но не затрагивают поиск, выделение и копирование встроенного текста PDF.

**Blocked by:** 01 — Базовая цепочка фильтров PDF и инверсия.

**Status:** ready-for-agent

- [x] В панели фильтров PDF доступен «Усиление текста» с выключенным начальным состоянием и согласованными рекомендованными значениями всех пяти параметров.
- [x] Параметры усиления текста отображаются только при включённом фильтре и становятся действующими после завершения перетаскивания соответствующего ползунка.
- [x] Переключение фильтра и завершённое изменение параметра обновляют только видимые и предзагруженные страницы; остальные страницы получают актуальный результат при появлении в области чтения.
- [x] Начальная фиксированная последовательность двух фильтров — «Усиление текста», затем «Инверсия»; действие «Сбросить все» восстанавливает этот порядок, выключает фильтры и возвращает рекомендованные значения.
- [x] Текстовый слой, поиск, подсветка совпадений и копирование текста остаются доступными и контрастными поверх фильтрованной страницы.
- [x] Пользовательские e2e-проверки покрывают управление фильтром, сброс, обновление по завершении действия и сохранность поиска; математический результат обработки не проверяется.
