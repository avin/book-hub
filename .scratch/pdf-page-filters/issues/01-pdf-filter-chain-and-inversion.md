# 01 — Базовая цепочка фильтров PDF и инверсия

**What to build:** Читатель PDF-книги может открыть панель фильтров PDF из верхней панели читалки, включить и настроить инверсию страницы и увидеть результат без постоянного цикла отрисовки. Настройки фильтра страницы PDF сохраняются отдельно для конкретной книги в браузере; при недоступном WebGL пользователь продолжает читать исходный PDF и получает понятное сообщение о недоступности фильтров.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [x] Панель фильтров PDF открывается из верхней панели, закрывает оглавление PDF и не нарушает существующие функции читалки.
- [x] Новая книга открывается с выключенной инверсией; при включении доступны её параметры, включая силу со значением по умолчанию 100 %.
- [x] Настройки инверсии хранятся отдельно для каждой книги в localStorage и восстанавливаются после повторного открытия этой книги.
- [x] Страница обрабатывается WebGL однократно для актуального состояния, без анимационного или непрерывного цикла отрисовки.
- [x] При недоступном или сбойном WebGL фильтры отключены с понятным сообщением, а PDF остаётся читаемым в исходном виде.
- [x] Пользовательские e2e-проверки покрывают открытие панели, взаимоисключение с оглавлением, параметры инверсии, сохранение по книге и доступную деградацию; математический результат обработки не проверяется.
