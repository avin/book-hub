# 03 — Изменение порядка цепочки фильтров PDF

**What to build:** Читатель PDF-книги может перетаскивать фильтры за специальную кнопку и задавать порядок цепочки фильтров страницы PDF. Порядок сохраняется для книги, применяется последовательно и не теряется, когда фильтр выключен.

**Blocked by:** 02 — Усиление текста для PDF-страниц.

**Status:** ready-for-agent

- [ ] У каждого фильтра в панели фильтров PDF есть специальная drag-кнопка для перемещения выше или ниже в списке.
- [ ] Новый пользовательский порядок определяет последовательность обработки включённых фильтров на отображаемых страницах.
- [ ] Выключенный фильтр сохраняет параметры и своё положение, а пользователь может переместить его до включения.
- [ ] Порядок цепочки фильтров страницы PDF сохраняется отдельно для конкретной книги и восстанавливается после повторного открытия.
- [ ] Изменение порядка применяется сразу к видимым и предзагруженным страницам без обработки всей книги в фоне.
- [ ] Пользовательские e2e-проверки покрывают перетаскивание, сохранение порядка выключенного фильтра и восстановление цепочки после повторного открытия; математический результат обработки не проверяется.
