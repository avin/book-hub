# 05 — Углубить lifecycle черновиков загрузки

**What to build:** подготовка нескольких книг к загрузке управляется единым lifecycle: выбор файла, извлечение названия и обложки, ручная правка, частичная ошибка, повтор и очистка ресурсов.

**Blocked by:** None — can start immediately.

Status: ready-for-agent

- [ ] Пользователь может загрузить несколько книг, включая книгу с ошибкой подготовки, не теряя успешно подготовленные черновики.
- [ ] Удаление черновика или уход со страницы освобождает связанные браузерные ресурсы и не оставляет незавершённые обновления состояния.
