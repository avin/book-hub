# 03 — Углубить module управления читалкой

**What to build:** FB2 и PDF используют общий module управления верхней и нижней панелями, поиском, оглавлением и шириной текста или страницы, сохраняя текущие правила показа и скрытия панелей.

**Blocked by:** None — can start immediately.

Status: ready-for-agent

- [ ] Верхняя и нижняя панели FB2 и PDF открываются и закрываются одинаково при наведении, поиске, касании и клике по тексту.
- [ ] Поиск по книге, оглавление FB2 и оглавление PDF остаются доступными с прежними ограничениями форматов.
