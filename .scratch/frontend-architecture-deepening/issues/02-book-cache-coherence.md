# 02 — Углубить module согласованности кэша книг

**What to build:** после изменения книги, обложки или прогресса библиотека и читалка показывают согласованные данные; callers не должны знать правила актуализации кэша и сортировки.

**Blocked by:** None — can start immediately.

Status: ready-for-agent

- [ ] Изменение избранного, метаданных и обложки корректно отражается во всех открытых представлениях библиотеки.
- [ ] Изменение и сброс прогресса обновляют индикаторы и порядок книг без дублирования cache-правил в callers.
