# 04 — Углубить module состояния библиотеки

**What to build:** поиск, фильтры, сортировка, пагинация, URL и выбранный вид библиотеки образуют одно проверяемое состояние, а страница библиотеки отображает его результат.

**Blocked by:** None — can start immediately.

Status: ready-for-agent

- [ ] Ссылка на библиотеку воспроизводит поиск, теги, сортировку и фильтр избранного.
- [ ] Ввод поиска, смена фильтров и пагинация сохраняют ожидаемый URL и не сбрасывают выбранный вид библиотеки.
