# Проверки описания книги

Дата: 2026-10-25.

## Итоговый прогон

- `make frontend-generate` — успешно; типы API сгенерированы из OpenAPI.
- `make test` — успешно:
  - все Go-пакеты, включая PostgreSQL store contract и жизненный цикл оригиналов;
  - frontend unit: 19 файлов, 88 тестов;
  - Playwright Chromium: 19 сценариев;
  - frontend typecheck и production-сборка, со штатной синхронизацией PDF/DJVU assets.
- `npm --prefix frontend run lint` — успешно.
- Prettier для изменённых frontend-файлов — успешно.
- `git diff --check` и `git diff --cached --check` — без ошибок.

Среда: Go 1.26.4, Node.js 24.18.0, npm 11.16.0, Windows.
PostgreSQL 17 запущен в отдельном временном Docker-контейнере;
пользовательская база не использовалась. SQLite использовал временные файлы тестов.
Набор PostgreSQL-пакета занял 378 секунд; завершился успешно.

Опциональные проверки реальных FTP/FTPS/S3 не запускались: тестовые сервисы
для них не настраивались. PostgreSQL backup/restore пропущен штатным условием
тестов из-за отсутствия подходящих `pg_dump`/`psql` в PATH. SQLite backup/restore,
включая восстановление старой схемы с пустым описанием, проверен.

## TDD и пользовательское поведение

- HTTP-тест сначала показал отсутствие описания в ответе; после реализации
  проверяет добавление, чтение, редактирование, очистку и пропуск поля в PATCH.
- Контракт хранилища сначала показал потерю описания в SQLite; после реализации
  проходит для PostgreSQL, SQLite и memory. Проверены персональные значения,
  отсутствие поиска по описанию и неизменность отклонённых записей.
- Граничные HTTP-тесты сначала выявили слишком малый multipart-лимит и отсутствие
  ограничения PATCH; после реализации проходят для кириллицы, трёхбайтовых
  символов, эмодзи, смешанных строк и превышения длины пробельным значением.
- Frontend-тест сначала выявил отсутствие multipart-поля; после реализации
  проверяет его передачу. Компонентные тесты проверяют вставку с выделением,
  нечётный остаток лимита перед эмодзи и нормализацию переносов.
- Браузерные проверки покрывают пустую и предзаполненную высоту, рост до десяти
  визуальных строк, прокрутку, уменьшение, изменение ширины, ограничение ввода,
  Enter в обеих формах, независимые черновики и сохранение описания после ошибки.
- Форма редактирования с многострочным описанием проверена визуально по скриншоту.
